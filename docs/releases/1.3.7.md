# [TaCZ] Weapon Research & Blueprints 1.3.7

Version 1.3.7 is a small compatibility update that removes the upper version
limit for Timeless and Classics Zero (TaCZ).

## Highlights

- Requires **TaCZ 1.1.8 or newer**, with no upper version limit in the mod's
  dependency requirement.
- Checked compatibility with **TaCZ 1.1.8-hotfix2**. Version 1.3.6 already
  accepts that hotfix; this update removes the restriction on later versions.

Newer TaCZ versions must still support Minecraft 1.20.1 and Forge. Future API
changes can require a compatibility update even though the version requirement
allows them.

## Updating

Replace the previous JAR with **1.3.7 on the server and every client**, keeping
only one version of this mod in each `mods` folder. Existing worlds, learned
blueprints, settings, and research progress carry over from 1.3.6. No world or
configuration reset is needed.

## Requirements

- Minecraft **1.20.1**, Forge **47.x**, and Java **17**.
- **Timeless and Classics Zero (TaCZ) 1.1.8 or newer**.
- **Fzzy Config 0.7.6 or later in the 0.7 series**, with its required
  dependencies, including Kotlin for Forge.
- Optional magazine integration supports **TaCZ Magazines 0.2.0-Beta**.
