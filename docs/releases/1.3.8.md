# [TaCZ] Weapon Research & Blueprints 1.3.8

Enable the included ammo and attachment Tech Trees directly from the server
settings. This update also explains why a research category is unavailable
and brings the new settings into Research Designer previews.

## Highlights

- Added **Ammo Research** and **Attachment Research** under **Server Settings →
  Research Progression** in Fzzy Config. Set either to **Enabled** to research
  that category, and keep the global **Enable Research** setting on.
- Each setting offers **Use Profile**, **Enabled**, and **Disabled**. The default
  **Use Profile** preserves your current datapack behavior. The built-in profile
  continues to enable weapons only until you opt into the other categories.
- Saving these settings refreshes connected players and open workstations
  without restarting or running `/reload`. Research costs, prerequisites, and
  individual blueprint restrictions still apply. Turning a category off keeps
  already learned blueprints.
- Research Bench category tooltips explain when server settings or the active
  profile disable research and point to the relevant category setting.
- Research Designer captures, previews, and warnings now follow these server
  choices. Existing captures retain their original profile behavior.

## Updating

Install **1.3.8 on the server and every client**, replacing the previous JAR.
The network format changed, so older clients cannot connect to a 1.3.8 server.
Existing worlds, learned blueprints, and research progress carry over; no reset
is needed.

You do not need an additional datapack to enable the bundled ammo or attachment
trees. If you installed the 1.3.7 enablement datapack only for this purpose,
remove that override and use the new settings so future bundled profile updates
can take effect. Keep any custom datapack changes you still need.

## Requirements

- Minecraft **1.20.1**, Forge **47.x**, and Java **17**.
- **Timeless and Classics Zero (TaCZ) 1.1.8 or newer**.
- **Fzzy Config 0.7.6 or later in the 0.7 series**, with its required
  dependencies, including Kotlin for Forge.
- Optional magazine integration supports **TaCZ Magazines 0.2.0-Beta**.
