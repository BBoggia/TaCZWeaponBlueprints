# [TaCZ] Weapon Research & Blueprints 1.1.1

Version 1.1.1 makes the research settings easier to understand and improves
Tech Tree layout customization. It also adds searchable item fields so common
server setup tasks no longer require memorizing resource IDs.

## Highlights

- **Clearer settings** — Server and Personal Settings are now organized by
  purpose, with advanced controls kept available without overwhelming the main
  configuration screens.
- **Reliable layout presets** — Compact, Balanced, and Spacious now produce
  distinct Tech Tree layouts. Unsupported combinations remain within safe
  visual limits, and Balanced provides a fallback if a custom layout cannot be
  prepared.
- **Searchable item fields** — Starting Blueprints, Blueprint-Free Item IDs,
  and gun, ammo, and attachment loot blacklists can be searched using loaded
  item names or resource IDs. Stored IDs remain valid while a content pack is
  temporarily unavailable.
- **Safer defaults** — Balanced is now the default discovery and loot preset
  for new installations. The default RP cap is 10,000, with a settings maximum
  of 100,000.
- **More helpful controls** — Settings that depend on another feature or
  preset now show when they are inactive and explain how to enable them.

## Fixes

- Fixed Compact, Balanced, or Spacious settings appearing to have no effect.
- Fixed oversized Spacious or Custom values causing the Tech Tree to disappear.
- Removed six legacy layout controls that no longer affect the visible Tech
  Tree while retaining migration support for existing configuration files.

## Updating

- No world migration is required. Existing progression and stored RP remain
  intact.
- Existing server discovery values and older client layout values migrate to
  Custom so their current behavior is preserved.
- Configured RP caps above 100,000 are reduced to 100,000. This does not delete
  RP already stored by players.
- Fzzy Config 0.7.6 or newer in the supported 0.7.x line is now required on
  both client and server.

## Requirements

- Minecraft 1.20.1
- Forge 47.x; validated with Forge 47.3.0
- Timeless and Classics Zero 1.1.8-hotfix (`1.1.8` up to, but not including,
  `1.2`)
- Fzzy Config 0.7.6 up to, but not including, 0.8
- Kotlin for Forge 4.11.x

JEI 15.x and EMI 1.1.x remain optional client-side integrations.
