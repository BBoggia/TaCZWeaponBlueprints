# [TaCZ] Weapon Research & Blueprints 1.3.10

Choose the jar for your Minecraft version and loader. Both builds require
**Timeless and Classics Zero (TaCZ) 1.2.0 or newer** for that same loader.

## Highlights

### Both builds

- Updated crafting Workbenches for TaCZ 1.2.0 while preserving learned-blueprint
  requirements and crafted-weapon origin tracking when outputs split into stacks.
- Added Marksman Rifle recipes to all three Crafting Workbenches. Their
  blueprints appear in the Rifle Blueprints creative tab with matching artwork
  sizing, names, and subgroup settings choices.
- Free factory attachment choices no longer block weapon analysis as removable
  attachments. Physical attachments still need to be removed first.
- Existing configuration values and saved blueprint knowledge are preserved.

### NeoForge 1.21.1

- Switched from the unofficial TaCZ port to the official NeoForge release.
- Added a settings landing page with **Quick Setup**, **Advanced Settings**,
  and **Personal Settings**. Quick Setup offers common progression choices;
  Advanced Settings retains detailed controls and searchable categories.
- Quick Setup and Advanced Settings share pending changes. Review the Gameplay
  Summary, then Apply or Discard. Conflicting server changes must be reviewed
  before applying an older draft.
- Added Recommended setup and Simpler Stations recipes with a before-and-after
  review. Unrelated custom settings are preserved.
- Simplified Personal Settings while preserving hidden legacy values. Appearance
  resets show their scope and wait for Apply.
- Fixed settings synchronization in singleplayer and LAN, open Analyzer preview
  refreshes after station changes, search cursor behavior, and screen-reader labels.

The new settings screens are NeoForge-only in this release. The Forge build
retains its existing Fzzy Config interface.

### Forge 1.20.1

- Ammo Research and Attachment Research now show readable choices and explanations
  in Fzzy Config. Existing configuration values are preserved.

## Updating

Back up your world and configuration, then update the addon on the server and
all clients. **NeoForge users must remove the unofficial TaCZ jar and install
TaCZ's official Minecraft 1.21.1 NeoForge jar.** Do not install both TaCZ ports.
Forge users need TaCZ's Minecraft 1.20.1 Forge jar.

No configuration reset is required. TaCZ moved some weapons into `dmr`; review
custom category exemptions and datapack rules if they should cover those weapons.
Custom Workbench tab lists need `tacz:dmr` to display Marksman Rifle recipes.

Forge and NeoForge worlds are not interchangeable. Third-party gun packs must
support the selected Minecraft version. TaCZ Magazines integration remains
Forge-only and its compatibility with TaCZ 1.2.0 must be checked separately.
