# Development design documents

`research-tree-fullscreen-redesign.md` is the canonical plan for the current
Research Bench fullscreen redesign.

The following completed phase series are historical implementation records.
They remain useful for explaining why the current code exists, but they do not
override the canonical fullscreen contract where the designs differ:

- `research-tree-phase-*.md`
- `research-tree-ui-ux-phase-*.md`
- `research-tree-navigation-phase-*.md`

New fullscreen work should link to the canonical document and record any
intentional contract change there before implementation.
