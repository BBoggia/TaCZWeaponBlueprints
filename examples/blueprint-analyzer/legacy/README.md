# Legacy Blueprint Analyzer reference

This complete profile matches the mod's bundled deterministic analysis settings.
It is a reference for pack authors; removing the tiered override normally
restores the bundled profile without this pack.

Do not enable it with the tiered profile override or its optional Analyzer rules.
It replaces the complete `taczweaponblueprints:duplicate_recovery` profile, so
merge changes into your own profile if other datapacks customize that ID.
